# 一组照片制作一套贴纸

用户提供一组照片时，默认制作一套统一画风的系列，通常每张内容照片对应一枚；不再询问是逐张、合并还是一套。用户明确要求合成一枚、不同画风或其他组织方式时按其要求执行。

先查看整组，为内容照片编号；用户指定的风格参考图单独标注，不计入贴纸数量。默认覆盖所有内容照片，不默默删除近似照片或合并内容。存在完全重复、无法读取或主体不明确的照片时说明具体编号，只处理必要歧义。

## 整套规划

结合整组内容提出 2–3 个有意义的系列元素方案，而不是逐张重复询问。每个方案简述整套记忆重点、人物与景物的主次原则，并列出每枚对应的主角及关键保留项。只有一个合理方向时不强凑选项；用户已有安排或授权自行决定时直接执行。

整套共用一份画风、文字模式、字形和装饰规则。画风可来自预设、用户描述或 [参考图提取](style-extraction.md)。共享协调的配色关系、线条和细节表达，允许各枚保留照片中的有意义颜色；主体、视角、比例和外形按各张内容变化，不强制同一布局。

## 分枚执行与汇总

为每枚分别组织完整 prompt：相同的系列画风要求，加上该枚内容、元素角色和实际展示文字。每枚使用对应照片，不把整组照片都传入每次生图而造成主体混用。跨照片组合仅在用户指定时执行。

支持生图时分别生成单枚图案，保存照片编号、实际 prompt 和作品对应关系；不支持时按编号分别给完整 prompt，不能只给一份公共模板让用户自行填空。

整套生成后，具备文件与预览能力时汇总到可放大的页面；其他环境按编号在对话展示。只有 prompt 时按编号汇总 prompt，不用占位图冒充作品。检查照片覆盖、主体对应和系列一致性；用户按编号修改或选定，不反复确认整套已确定的规则。

打印仍为用户要求时才进入的分支；只排版最终选定图案，不在定尺寸时重新生成。
