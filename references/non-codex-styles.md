# 非 Codex 通道的画风要求

在非 Codex agent 中，无论直接生图还是仅交付 prompt，选定预设后将对应的具体要求填入公共框架的“画风”字段，不能只写名称。画风名称可保留作标签；只采用选中的一条，不把整份表塞入 prompt。当前 agent 所在平台决定通道，不由目标生图模型或文件位置决定；环境不明时使用非 Codex 通道，无须询问。

以下要求是画风转译指引，不代表已经在其他平台验证。用户补充优先；自定义画风不强行套用预设，描述其可观察的造型、线条、色彩和图文特点。画风适用于人物、建筑、景物和物品，不锁定相同姿态、构图或装饰。保留主体辨识依据，文字内容仍由“展示文字”决定，不将画风名称印到图案中。

| 画风 | 填入 prompt 的具体要求 |
| --- | --- |
| 三丽鸥风格 | 甜美可爱的平面插画，圆润柔软的轮廓与适度夸张比例，简洁五官、轻柔线条和糖果粉彩；主体与小花、星点等装饰共享可爱造型，文字采用圆润字形。不要自动加入现成角色。 |
| 迪士尼画风 | 经典动画电影插画，流畅的轮廓、富有表情与动作感的主体、圆滑而有体积的形体；用清楚的明暗层次和温暖光色塑造空间，字形与画面的故事感协调。不要自动加入现成角色。 |
| 蜘蛛侠：平行宇宙风格 | 漫画与动画融合，锐利轮廓、动态透视和不对称构图，鲜明撞色；以半调网点、印刷错位和局部色边表现质感，文字融入漫画式图形节奏。不要自动加入蜘蛛侠角色。 |
| 包豪斯 | 将主体结构提炼为圆、矩形、三角和明确的线段，以几何比例、负空间与不对称平衡组织构图；使用原色与黑白的克制组合，文字采用清楚的几何无衬线字形。 |
| 乐高 | 将主体重新搭建为可辨认的积木构件，体现凸点、拼接缝、硬质塑料与模块化轮廓；人物采用积木人式造型，建筑和物品也按积木结构重构，图案仍以单枚贴纸正面呈现。 |
| 扁平化 | 用干净轮廓和边界清楚的实色色块概括主体，靠色块大小、遮挡与留白建立层次；压缩连续明暗与表面纹理，文字与图形形成简洁的平面构图。 |
| 复古logo | 复古旅行标志插画，提炼主体识别轮廓，与徽章式边框或弧形文字共同构图；使用有限复古配色、清楚线条及少量旧印刷颗粒，标题采用有年代感的招牌字形。 |
| 苹果扁平化设计 | 清爽精确的现代图标语言，平滑几何轮廓、圆角与充分留白，减少无关细节；使用明快而协调的颜色，必要的渐变只用于轻微层次，搭配简洁无衬线文字。 |
| 8位机像素风 | 按统一粗像素网格重绘所有主体、文字与装饰，轮廓呈清楚阶梯，使用有限调色板和离散像素阴影；避免平滑曲线、抗锯齿和在普通插画上叠加像素滤镜。 |
| 女神异闻录风格 | 高对比的图形化日式角色插画，黑白与醒目强调色形成锐利色块，斜切边缘、强烈对角线和有节奏的留白；文字与角形图块穿插，人物和景物统一为戏剧化图形语言。 |
| 纪念碑谷风格 | 等轴测与不可能空间式的建筑图形语言，主体提炼为简洁立体几何体，用柔和色面区分朝向，营造安静梦幻的空间；人物也作协调的几何概括，文字保持轻巧清楚。 |
| 极简mg风 | 动态图形设计的静帧语言，以少量基础几何形和大色块表达主体，用负空间、比例与排列节奏建立视觉重点；五官和纹理作符号化概括，采用醒目简洁的无衬线文字。 |
| line风格 | 可爱聊天贴图语言，圆润且有弹性的角色轮廓、粗而干净的描边、简洁表情与夸张动作；采用平涂色和清楚剪影，景物同样作圆润概括，文字像亲切的手写贴图。 |
| 木刻版画 | 以刀刻式轮廓、黑白或有限套色的对比表现主体，保留刻痕、排线和粗粝印刷纹理；用疏密线条塑造明暗，文字具有刻版感，建筑、人物与装饰统一为版画。 |
| 彩色玻璃 | 把主体分解为由深色铅条连接的彩色玻璃片，用玻璃块的形状和透明色光表达结构；人物与景物都采用镶嵌分区，文字和边框协调融入，不用真实照片充当玻璃区域。 |
| 街头pop | 街头海报与波普插画融合，饱和撞色、粗描边和醒目图块，结合网点、喷绘或涂写质感；标题夸张有节奏，主体、文字和装饰形成有冲击力的平面构图。 |
| 低多边形 | 以可见的三角或多边形色面重构所有主体，靠面片方向和明暗表现体积；轮廓与内部结构具有明确折面，避免圆滑渐变和只对背景施加多边形效果。 |
| 二次元卡通 | 日式动画插画，清楚而有变化的线条、富有表情的五官、分组的发束和赛璐璐阴影；景物与角色共享动画化色彩和线条，文字配合画面的情绪与节奏。 |
| 小尺寸贝壳像素材料印章 | 小型像素印章构图，以清楚的像素阶梯概括主体，在像素块内部体现贝壳珍珠母的虹彩反光；外围紧凑，文字使用可读像素字，不用光滑照片加虹彩滤镜替代像素重绘。 |
| 超现实主义 | 在保留主体识别特征的同时，创造梦境式尺度、空间或物体关系，用意外但有视觉逻辑的组合表达旅行记忆；光影与形体服务于梦境，文字融入超现实构图，不只叠加发光特效。 |
| 韩式可爱平面 | 亲切的手绘平面插画，柔软不规则轮廓、简洁点状五官、奶油与粉彩色块，保留轻微手画感；人物、景物和小装饰共同形成轻松构图，字形圆润自然。 |
| 辛普森一家风格 | 电视卡通式平涂插画，人物采用黄色皮肤、圆大白眼、简洁鼻口和粗黑轮廓，保留原人物的发型服装辨识；景物以同样的清楚线条与简化色块重画。不要自动加入现成角色。 |

生成后核对这些可观察特征是否成立。只有配色改变而造型、构图或材质未体现对应要求时，按缺失特征进行一次针对性修正；不将“写过画风要求”当作效果验证。仅交付 prompt 时说明尚未验证生成结果。
