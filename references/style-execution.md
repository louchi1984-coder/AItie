# 出图与对照

1. 从照片与用户意图中确定内容和元素角色。
2. 公共框架保持稳定，Codex 通道填入简短画风名称与用户补充；非 Codex 通道填入 [具体画风要求](non-codex-styles.md) 中对应条目。用户自填画风原意保留，也不把样式表的所有说明塞入提示词；选多个样式分别生成，明确要求融合时才混合。
3. 用原照片提供内容依据；用户指定的风格参考提供画法依据。历史样张不自动成为模板。
4. 实际提示词只包含本次创作需要的信息。自由创作范围与要保留的主体特征分开，避免同时要求照片级还原和重新造型。
5. 按整体吸引力、主体对应、画法区分、图文组织检查。不是细节越少越好，也不是只有换配色就算换画风。
6. 保留每版和实际提示词。局部错误先局部改，不重画已成立的主体。连续两次没有改善就保留更好版本，说明具体问题；不要无限追加约束。

图片生成与打印排版是两阶段。选定作品后只缩放排版，尺寸变化不触发重绘。探索样例不等于已认可成品。
