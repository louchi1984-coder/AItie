# 验证范围

## 内容与创作

- 未指定元素逻辑时，先按实际照片给出成立的选项并推荐，用户选定后生成；已明确安排或授权自动设计时不重复询问。
- 建筑主导、游客仅为环境的照片不凭空提出人物主角；三类主体是分析工具，不是固定用户菜单。

- 同一元素（例如观众）能够因用户意图成为主体、辅助、图文装饰或舍弃。
- 人物、风景、物品可使用所有画风；核心识别依据不被装饰替代。
- 地点特色元素与主题协调，不因照片里没有就判错；不猜未知地点。
- 文字三个模式有效，测试标题与地点不进入通用默认。
- 展示文字与补充信息独立：补充地点不会自动变成标题或其外语译名；无字模式即使提供地点也不印字；自由设计遵循展示字段的范围。
- 不固定姿势、外形、比例和细节数量。多风格应在画法上可辨。

## 打印排版

- 非正方形图案保持比例，宽高自动计算。
- 依图案像素和 min_ppi 限制尺寸；低分辨率不足以满足可读尺寸时明确报错。
- small/medium/large 自动产生不同可行大小，不能在钳制后重复冒充三种尺寸。
- 每款各尺寸数量准确，多页无丢失、重叠或越界。
- 清单中所有数值有效，图像和 JSON 路径支持空格；相对路径以清单所在目录为基准。
- PDF 页框、尺寸记录与图案一致；渲染查看真实结果。裁切辅助框不能宣称异形刀线。

结构验证不证明图像好看，样例保留未通过状态。六画风 × 三题材是18个组合；可按改动范围分批验证，未跑的组合不宣称已通过。
