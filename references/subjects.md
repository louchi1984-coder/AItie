# 元素角色与可调变量

元素提取不是单一的“细节多少”。先识别照片内容，再按表达目的重分配角色。

## 先提出基于原图的方案

用户未确定元素逻辑时，先看原图，提出通常 2–3 个有实质差别且成立的方案，标注推荐项，等待用户选择后再生图。选项用具体内容命名，逐项交代谁当主角、什么保留、什么转为图文装饰、什么舍弃；画法和文字偏好另行处理，不混成元素方案。

例如圣母院广场照片，建筑清楚、人群只是环境，没有明显人物主角，可提供：
- 建筑主体：只保留圣母院，与文字组成贴纸；舍弃场景杂项。
- 现场氛围：建筑为主，人群、树木和广场为辅助，保留游览现场。
- 元素重组：建筑为主，树木和人群剪影转为图文装饰，舍弃完整场景布局。

这些不是固定菜单。照片不存在明确人物主角时不凑“人物记忆”，不从匿名人群任意挑人升为主角。人物主体方案须有原图的明确视觉依据或用户指定。内容只支持一个合理方案时说明并推荐，不强凑多选。用户已指定元素安排、已选方案或授权自主设计时直接执行。

| 角色 | 设计用途 |
| --- | --- |
| 主体 | 视觉中心，可以把照片中原本次要的元素升为主角 |
| 关系辅助 | 保留动作、互动、地点或故事所需的关系 |
| 图文装饰 | 提炼轮廓、局部或符号，与文字、边框、留白组合 |
| 舍弃 | 无关、重复或破坏构图的元素，不因照片里有就全部保留 |

例：演唱会观众可作为主体纪念“我们一起看演出”；可作背景人群表达气氛；可变成标题旁的剪影；只突出舞台时可舍弃。角色由意图决定，不由“观众”这一类别固定。

## 三类内容逻辑

- 人物：保留身份、关键配件与活动含义，允许画家式重新造型。动作相关道具往往比背景更重要；多人照片不自动将所有人变成主角。主体选择与人数取舍需符合用户记忆重点。
- 风景：识别独特轮廓、地标与空间；可以重新安排视觉层次，但别把特定地点替换成无关通用景观。
- 物品：结构、材质、包装或地方联系决定识别性。它可以独立成为主角，也可与人物、标题组成记忆符号。
- 混合：主次与关系共同决定布局，所有元素共享所选画法。

## 可调变量与自动默认

| 变量 | 选择 | 未指定时 |
| --- | --- | --- |
| 元素角色 | 指定突出、辅助、装饰、删除的元素 | skill 根据意图分配 |
| 场景保留范围 | 主体为主／保留关键关系／完整情境 | 保留表达记忆所需关系，不控制画法细节 |
| 特色元素 | 自动补充／指定元素／不补充 | 从已知地点和主题选择协调内容 |
| 展示文字 | 指定／自由设计／无字；语言与创作范围 | 自由设计主题文案，不自动取用补充信息中的专名、日期或说明 |
| 补充信息 | 地点、故事、背景说明 | 仅用于理解内容与选择特色元素，不自动印字 |
| 装饰 | 克制／适量／丰富 | 按画风和构图决定 |
| 外形 | 自动／用户指定形状 | 根据构图决定，不让用户填宽高 |
| 系列 | 独立设计／同系列 | 多风格比较各自独立；系列统一视觉语言 |

地点、用户故事、颜色偏好均可作为补充输入。补充信息和展示文字是独立字段：例如补充信息为“巴黎圣母院”，可帮助识别建筑和选择装饰，但并不要求印“巴黎圣母院”“Notre-Dame”或“Paris”。只有展示文字明确指定或授权使用该地点名称时，才把它作为文案。变量是可选控制，不是必填问卷。不要把“主体为主”解释成简笔画。

## 地点与特色元素

已知地点可引出地方植物、建筑符号、食物、纹样、交通或节庆元素，按构图分配角色。用户提供的具体要求优先。真实文化符号不确定时查证；通用太阳、星点、花草可作为创作装饰。未知地点不猜名字，仍可完成一般旅行主题。装饰不是实拍事实，介绍时不要冒充照片中的景物。
